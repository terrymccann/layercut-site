> **During the beta, every feature is free.** Pro features are unlocked in every version before 1.0. License keys start with version 1.0.

## What each edition includes

| Feature | Free | Pro |
|---|---|---|
| Stacked, including hollow layers, pins, labels and guides | ✓ | ✓ |
| Interlocking grid and radial, including hollow shells | ✓ | ✓ |
| Panels and living hinges in the 3D and Sheets views | ✓ | ✓ |
| Export panels and living hinges | | ✓ |

| LightBurn .lbrn2 export | | ✓ |
| Materials, fit test, true-shape nesting | ✓ | ✓ |
| Updates | Always | 12 months included, then $25 a year to renew |
| Price | Free | $59, one-time |

The free edition is free forever, for personal and commercial work.

## How a Pro license works

- **Buy once, keep it.** Pro keeps working forever on every version released during your update year.
- **Updates for a year.** Every version released in the 12 months after you buy is included. After that you can keep using the last version you're covered for, or renew for another 12 months.
- **If you install a newer version** after your updates have ended, it runs as the free edition and offers to renew. Older versions stay available to download.
- **No account or activation server.** The license key is checked on your computer, so LayerCut works offline.
- **One person, any computers.** Use your license on your own desktop and laptop. Your name appears under **About LayerCut**.

## Entering a license key

Choose **LayerCut → License…** on a Mac, or **Help → License…** on Windows. Paste the key from your email, or click **Load license file…** and choose the file attached to it. Pro features unlock straight away.

Lost your key? See [License keys](/license/).
