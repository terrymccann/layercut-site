---
title: Keyboard shortcuts
intro: On Windows, use Ctrl wherever a Mac shortcut uses ⌘.
---

## Files and views

| Action | Mac | Windows |
|---|---|---|
| Open a model | <kbd>⌘O</kbd> | <kbd>Ctrl+O</kbd> |
| Export cut files | <kbd>⌘E</kbd> | <kbd>Ctrl+E</kbd> |
| 3D view | <kbd>⌘1</kbd> | <kbd>Ctrl+1</kbd> |
| Sheets view | <kbd>⌘2</kbd> | <kbd>Ctrl+2</kbd> |
| Zoom to fit | <kbd>⌘0</kbd> | <kbd>Ctrl+0</kbd> |
| Switch light and dark | <kbd>⇧⌘L</kbd> | <kbd>Ctrl+Shift+L</kbd> |

## Materials

| Action | Mac | Windows |
|---|---|---|
| Manage materials | <kbd>⇧⌘M</kbd> | <kbd>Ctrl+Shift+M</kbd> |
| New material | <kbd>⇧⌘N</kbd> | <kbd>Ctrl+Shift+N</kbd> |

## Sheets view

| Action | Keys |
|---|---|
| Next or previous sheet | <kbd>→</kbd> <kbd>←</kbd>, or <kbd>Page Down</kbd> <kbd>Page Up</kbd> |
| Zoom in or out | <kbd>+</kbd> <kbd>−</kbd>, or scroll |
| Fit the sheet | <kbd>0</kbd> |
| Clear a highlighted piece | <kbd>Esc</kbd> |

## Moving slices

| Action | Keys |
|---|---|
| Drag in 0.5 mm or 0.5° steps | Drag |
| Drag in 0.1 mm or 0.1° steps | <kbd>Shift</kbd> + drag |
